# Excel งบโครงสร้างสำหรับเสนอผู้บริหาร

**ฉบับล่าสุดแบบเรียบง่าย:** [structure-budget-simple.xlsx](structure-budget-simple.xlsx) — ชีตเดียว ตารางสามคอลัมน์ รายการ/ราคาต่ำ/ราคาสูง รวมเงินเผื่อและหมายเหตุสั้น ๆ พิมพ์ A4 หน้าเดียว ตัวเลขเดิมไม่เปลี่ยน สร้างซ้ำด้วย `python docs/budget/build-simple-workbook.py` ตรวจยอด/สูตรและหน้าพิมพ์ผ่านแล้ว

ฉบับสามชีตเดิมอยู่ด้านล่างสำหรับดูรายละเอียดเพิ่มเติม

[ดาวน์โหลด structure-budget-th.xlsx](structure-budget-th.xlsx) · จัดทำ 24 ตุลาคม 2026 (Asia/Bangkok)

ใช้ข้อมูลจาก [งบโครงสร้าง](../structure-budget-th.md) ฐานประมาณการ 23 ต.ค. 2026 ไม่ใช่ใบเสนอราคาหรืออนุมัติจัดซื้อ ตัวเลขเดิมไม่เปลี่ยน: ก่อนเผื่อ 66,000–107,000 บาท รวมเผื่อ 20% 79,200–128,400 บาทต่อเครื่อง ปัดเพื่อคุยทีม 80,000–130,000 บาท

มีสามชีต:

1. **สรุปเสนอผู้บริหาร** — สรุปสี่หมวด ยอดรวม เงินเผื่อ ช่วงปัด และข้อยกเว้น ตั้งหน้าพิมพ์ A4 แนวนอนหนึ่งหน้า
2. **รายละเอียดงบ** — รายการที่รวม แหล่งข้อมูล/สถานะ และสูตรรวม แก้ราคาต่ำ–สูงช่องสีน้ำเงิน D8:E11 และอัตราเผื่อ B5 ได้ สรุปเชื่อมสูตรอัตโนมัติ
3. **สมมติฐานและไม่รวม** — เงื่อนไขฐานราคา ข้อยกเว้น และสิ่งที่ต้องขอราคาจริง ไม่มีการใส่ศูนย์แทนรายการที่ยังไม่ทราบราคา

ตัวเลขทุกหมวดเป็นต่อหนึ่งเครื่อง ไม่ใช่ราคาต่อชิ้น ไม่มีการแตกราคาเหล็ก ค่าแรง ล้อ หรือชิ้นส่วนย่อยโดยไม่มีข้อมูล สูตรปัดช่วงราคาเป็นหลักหมื่นเพื่อสื่อสาร ไม่ใช่เพดานงบ เมื่อแก้ราคาให้ตรวจยอดจริงก่อนใช้ช่วงปัด

## สร้างไฟล์ซ้ำ

ใช้ Python พร้อม `xlsxwriter`:

```sh
python docs/budget/build-workbook.py
```

สคริปต์ตั้งสูตรและ cached results เพื่อให้โปรแกรมดูตัวอย่างอ่านยอดตั้งต้นได้ และตั้งคำนวณอัตโนมัติเมื่อเปิดไฟล์ หากแก้สมมติฐานในสคริปต์ต้องปรับ cached results ที่เกี่ยวข้องให้ตรงก่อนเผยแพร่ ห้ามรันสร้างซ้ำทับไฟล์ที่ทีมแก้ไขราคาโดยไม่เก็บสำเนา

## ผลตรวจฉบับนี้

- เปิดตรวจด้วย openpyxl ทั้งสูตรและ cached values: จำนวนชีต การเชื่อมแต่ละหมวด ยอดก่อนเผื่อ เงินเผื่อ ยอดรวม และช่วงปัดตรงข้อมูลต้นทาง
- มี data validation สำหรับราคาต่ำ/สูงและอัตราเงินเผื่อ พร้อมเน้นกรณีช่วงราคาผิด ไม่ใช้สูตรลิงก์ไป workbook ภายนอก ไม่มี macro
- ทดสอบสำเนาแยกโดยเปลี่ยนโครงหลักด้านต่ำเป็น 31,000 บาทและเงินเผื่อเป็น 25% แล้วให้ LibreOffice คำนวณใหม่ ยอดต่ำ/สูงรวมเผื่อได้ 83,750/133,750 บาท ป้ายอัตราเผื่อและสรุปปรับตามสูตร
- เปิดด้วย LibreOffice และส่งออก PDF เพื่อตรวจทั้งสามหน้าพิมพ์ ตรวจภาพหน้าสรุปและสมมติฐานแล้ว ไม่ได้ทดสอบใน Microsoft Excel โดยตรง
- ไม่ได้ขอราคาผู้ผลิตใหม่หรือยืนยัน VAT/ขนส่งจากการจัดทำไฟล์นี้
