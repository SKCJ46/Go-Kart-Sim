# สไลด์สรุป Project Context v2.3

จัดทำ 23 ตุลาคม 2026 (Asia/Bangkok) จาก [Context หลัก](../Gokart_IDEA/PROJECT_CONTEXT.md) เพื่อคุยทีมและผู้บริหาร ไม่มีการเปลี่ยนข้อกำหนดหรืออนุมัติข้อเสนอเพิ่มเติม

- [เปิด HTML 16 หน้า](team-slides-th.html): ดาวน์โหลดแล้วเปิดด้วยเบราว์เซอร์ ใช้งานนำเสนอออฟไลน์ได้ ภาพและฟอนต์ฝังอยู่ในไฟล์เดียว
- [PDF 16 หน้า](project-context-slides-v2-3.pdf): A4 แนวนอน สำหรับส่งต่อ/พิมพ์ เป็นเนื้อหาเดียวกับ HTML ณ วันที่จัดทำ ภาพระยะใน PDF ใช้มุมข้าง ส่วน HTML สลับมุมบนได้
- HTML ใช้ลูกศรซ้าย/ขวา Space หรือ Page Up/Down เปลี่ยนหน้า; Home/End ไปต้น/ท้าย; ปุ่มสารบัญเลือกหัวข้อ; F หรือปุ่มเต็มจอสำหรับอุปกรณ์ที่รองรับ; มือถือปัดซ้าย/ขวาและเลื่อนอ่านแนวตั้งได้
- แตะภาพเพื่อขยายได้ถึง 175% แล้วเลื่อนดูรายละเอียด กด Escape เพื่อปิด
- เอกสารอ่านเพิ่มอยู่ท้ายสไลด์สุดท้าย ลิงก์เหล่านี้ต้องมีโฟลเดอร์โปรเจกต์ประกอบ แม้นำเสนอหลักได้จาก HTML ไฟล์เดียว

## เนื้อหา

1. เป้าหมายเครื่องพร้อมโชว์
2. รูปแบบเครื่องที่ตกลงแล้ว
3. ข้อเสนอคลาสรถ: X30 Senior และการเผื่อต่อยอด KZ2
4. ขนาดและท่านั่งตั้งต้น พร้อมภาพพิกัดสองมุม
5. Drawing สามมุม Rev A
6. วัสดุและแนวทางประกอบ
7. ภาพรวมการทำงานของระบบ
8. จอ Motion น้ำหนัก และข้อจำกัด GM5
9. Feeling และตัวเลือกเกม
10. งบโครงสร้างแยกรายการ รวมเบาะ ล้อและขาจอ และรายการยังไม่รวม
11. Mark / Chin และบทบาทที่ยังต้องระบุ
12. ร่างเกณฑ์พร้อมโชว์
13. เรื่องอุปกรณ์/งบ/จำนวนเครื่องที่ต้องตัดสินใจ
14. วันโชว์ เวลาทีม และผู้ตรวจรับ
15. ลำดับงานก่อนเครื่องพร้อมโชว์
16. ข้อมูลที่ต้องหาเพิ่มและเอกสารอ่านต่อ

## สถานะข้อมูล

สไลด์งบรอบล่าสุดแสดงเฉพาะโครงสร้างตามคำสั่งผู้ใช้: ก่อนเผื่อ 66,000–107,000 บาท รวมเผื่อ 20% 79,200–128,400 บาท (ปัด 80,000–130,000 บาท) ไม่รวมอุปกรณ์ Sim/Motion, PC และจอ ดู [รายละเอียดขอบเขต/ข้อยกเว้น](structure-budget-th.md) ตัวเลขไม่ใช่งบทั้งเครื่องพร้อมโชว์

ป้ายยืนยันแล้วใช้เฉพาะข้อสรุปผู้ใช้ มิติ วัสดุ X30 Senior งบและเกณฑ์ทดสอบเป็นข้อเสนอ/ประมาณการ ข้อมูลผู้ผลิต GM5 ยังต้องตรวจร่วมกับเครื่องจริง ภาพ Drawing เป็นภาพสร้าง raster ไม่ใช่ CAD หรือแบบผลิตที่ตรวจแล้ว วันที่ 29 ต.ค. เป็นเป้าพร้อมข้อมูลประชุม ไม่ใช่วันเครื่องเสร็จ

Brief HTML/Word/PDF ชุดเดิมยังเป็นฉบับ 21 ต.ค. ไฟล์สไลด์นี้อัปเดตตาม Context v2.3 แล้ว

## การตรวจฉบับนี้

- ตรวจด้วย Chromium/Playwright: 16 หน้า ภาพฝังโหลดครบ ไม่มี JavaScript error และไม่มีเนื้อหาล้นกรอบที่ 1440×900 และ 1280×720
- ทดสอบ viewport มือถือ 390×844 ไม่มีล้นแนวนอน ใช้การเลื่อนแนวตั้งอ่านเนื้อหา ไม่ใช่ผลทดสอบบนโทรศัพท์จริง
- ตรวจคีย์บอร์ด ปุ่มก่อน/ถัดไป สารบัญ การขยายภาพ 175% และการสลับภาพระยะมุมบน/ข้าง
- PDF ส่งออกจาก Chromium ผ่าน print stylesheet: A4 แนวนอน 16 หน้า ตรวจภาพรวมสไลด์และภาพ PDF หน้างบ
- ตรวจ diff และลิงก์ไฟล์ในเอกสารที่แก้; ภาพเดิมไม่ได้ถูกแก้ไข ไม่มีการทดสอบฮาร์ดแวร์หรือการรับรองความพร้อมโชว์จากงานนำเสนอนี้
