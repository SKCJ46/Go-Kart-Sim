# ชุดอุปกรณ์ขับสำหรับ Go-kart Simulator — ผลศึกษา 26 ต.ค. 2026

สถานะ: ข้อเสนอเปรียบเทียบตามคำขอผู้ใช้ให้ค้นหา Fanatec/Simagic และแบรนด์อื่นได้ ยังไม่เลือกแบรนด์ รุ่น งบหรืออนุมัติซื้อ ไม่เปลี่ยนงบ Excel โครงสร้าง 80,000–130,000 บาท และไม่เปลี่ยนขอบเขต Active brake เอง

## ข้อเสนอหลัก

ให้น้ำหนัก **SIMAGIC Alpha EVO 12 Nm + พวงมาลัยกลม + ชุดแป้นแบบสองแป้น** เป็นฐานเปรียบเทียบ คุยสองสเปก: (1) P1000 Formula Standard / P1000-F แบบ Load Cell สำหรับเทียบและพิสูจน์ระบบ และ (2) P-Active เบรกหนึ่งแป้น + คันเร่ง สำหรับทางเลือก Active ตามเป้าเดิม การเสนอ Load Cell ไม่ใช่คำอนุมัติใช้แทน Active หรือซื้อทั้งสองชุด

วง GTS Leather 300 มม. เหมาะกับกรอบลองท่านั่ง 300–320 มม. ของเรา แต่ยังไม่ยืนยันราคาไทย/สต็อกในรอบนี้ ส่วน NEO X-330R 330 มม. มีราคาไทยที่แยกรุ่นได้ จึงใช้ประกอบยอดเปรียบเทียบ ต้องลองเส้นผ่านศูนย์กลางที่ใหญ่กว่ากรอบเดิมเล็กน้อยว่าติดเข่าหรือไม่ และยืนยันของในชุด (rim+hub+QR) ก่อนสั่ง

เหตุผลเป็นดุลยพินิจออกแบบ ไม่ใช่ผลทดสอบเปรียบเทียบจริง: ฐานระดับ 12 Nm มีแรงสำรองให้ปรับโปรไฟล์ ใช้ระบบอุปกรณ์เดียวกันได้หลายส่วน และมีเส้นทางเปรียบเทียบ P1000/P-Active ไม่จำเป็นต้องเริ่มด้วย 18–25 Nm การเลือกฐานแรงสูงไม่ได้หมายถึงเปิดแรงเต็มกับผู้ทดลองทุกคน เริ่มต่ำแล้วเทียบกับผู้ขับจริงตามแผน

## Fanatec: จุดแข็งที่เกี่ยวกับงานนี้

[CSL Elite Pedals V2](https://www.fanatec.com/us/en/p/pedals/csl_ep_v2/csl-elite-pedals-v2) ระบุให้ถอดฐานพักเท้าและติดตั้งแป้นแต่ละตัวแยกได้ ใช้สองแป้นได้ ต่อ PC ผ่าน USB หรือฐาน Fanatec ผ่าน RJ12 จึงมีหลักฐานผู้ผลิตชัดเรื่องติดตั้งแยก แต่ความยาวสายเดิมเมื่อเว้นช่องพวงมาลัย/ระยะเท้ายังต้องตรวจจริง

[Fanatec Torque FAQ](https://help.fanatec.com/hc/en-us/articles/48812077676177-Wheel-Base-Torque-FAQ) ระบุ ClubSport DD ปัจจุบันสูงสุด 15 Nm และ DD+ 18 Nm หลังอัปเดตเดือน พ.ค. 2026 ต้องใช้ Fanatec app ปัจจุบัน ภาพสินค้า/เอกสารเดิมที่เขียน DD 12 Nm จึงไม่ใช่สเปกสูงสุดล่าสุด รุ่น DD+ เพิ่มความสามารถ PlayStation ซึ่งยังไม่จำเป็นสำหรับโครงการ PC นี้

ต้องตรวจ hub/QR และวงที่เลือกให้ครบ บางวง CSL เช่น P1 V2/WRC/BMW จำกัดแรงไว้ 8 Nm แม้ใช้ฐานใหญ่และเปลี่ยน QR จึงไม่เสนอเอาวงเหล่านี้จับฐาน ClubSport แล้วคิดว่าได้แรงเต็มเสมอ ส่วน FullForce ต้องตรวจว่าเกมส่งสัญญาณเฉพาะนี้ได้จริง ไม่อนุมานจาก FFB ปกติหรือใช้แทน Motion

## SIMAGIC: จุดที่ต้องพิสูจน์

[P1000 ผู้ผลิต](https://simagic.com/pages/details-p1000) มีแบบสองแป้น P1000-F และโครงสร้าง Modular พร้อมการปรับแป้น/เซ็นเซอร์ Load Cell; [คู่มือ](https://image.simagic.com/profile/upload/2024/07/18/SIMAGIC_P1000_UM.pdf) มีมิติและการต่อ แต่คำว่า Modular ไม่ใช่หลักฐานว่าถอดย้ายแป้นกว้างเท่าใดก็ได้ ต้องตรวจสาย/control box และขอแนวทางติดตั้งแยกที่ผู้ผลิตยอมรับก่อนล็อก CAD ไม่ตัด/ต่อสายโดยสมมติว่ารองรับแล้ว

[P-Active ผู้ผลิต](https://simagic.com/products/simagic-p-active-pedal) ยังระบุ Pre-Order / Ships Nov 18 ณ วันที่ตรวจ ไม่ใช่วันถึงไทยที่ยืนยันแล้ว จึงต้องแยกความเสี่ยงเวลาส่งจากกรอบ 12+2 สัปดาห์ Active มีไว้ศึกษาแรง/ระยะและการตอบสนองที่แป้น ส่วน HPR เป็นการสั่นเสริม ไม่ใช่ Active pedal และเกมโกคาร์ทไม่จำเป็นต้องมี ABS/TC จึงไม่ใช้ effect เหล่านี้เป็นเหตุผลหลักในการเลือก

การต่อ USB ใช้บน PC ได้ไม่ได้รับประกันว่า KartKraft/Kart Racing Pro จะมีทุก effect การ bind แกนเบรก/เร่ง FFB telemetry Motion และ Active/haptic ต้องทดสอบแยก รวมถึงท่านั่งต่ำ ความแข็งแรงแท่นแรงเบรกและ failure modes

## ทางเลือกอื่นที่สำรวจ

MOZA R12 V2 + พวงมาลัยกลมที่เลือก + CRP2 เป็นตัวเลือกเพิ่มได้ ผู้ผลิตมี [ข้อมูลฐาน/จุดยึด](https://support.mozaracing.com/en/support/solutions/articles/70000668789-moza-r12-wheel-base-support) และ [คู่มือ CRP2](https://image.gudsen.com/mozaracing/Pedals/crp2/MOZA%20CRP2%20User%20Manual%20EN-min.pdf) แต่ยังไม่ทำยอดราคาไทยที่เทียบรุ่นครบหรือพิสูจน์การแยกแป้น จึงไม่จัดอันดับเหนือสองแบรนด์หลักตอนนี้

## สิ่งที่ต้องตรวจให้ครบก่อนเลือก/สั่ง

1. ทดลอง mock-up วง 300/330 มม. กับคนจริง ตรวจเข่า การจับและองศาติดตั้งฐาน
2. แยกเบรกซ้าย–คันเร่งขวาตาม layout (ระยะเท้าตั้งต้น 320–400 มม.) ตรวจสายและรูปแบบยึดโดยไม่ดัดแปลงนอกข้อกำหนด
3. ทดสอบอุปกรณ์ที่จัดหาได้กับเกม/GM5/SimHub จริง เก็บแรงพวงมาลัย/แรงเบรกและ effect ที่ใช้ได้ ไม่ล็อกตัวเลขแรงจากสเปกสูงสุด
4. ตรวจการหยุดของ Motion/FFB/Active แยกกัน และการกลับมาทำงานหลังสัญญาณหรือไฟหาย
5. ยืนยัน contents, QR, adapter, แหล่งจ่ายไฟ สายเพิ่มเติม รุ่น firmware ราคา/ภาษี/ส่ง และวันจัดสรรจริง
6. ยืนยันเงื่อนไขประกัน/การใช้สาธิตหรือเชิงพาณิชย์และตารางพัก คู่มือ GTS มีข้อแนะนำระยะเวลาขับ/พักสำหรับผู้ใช้ ไม่ใช้เป็นหลักฐานรับรองความทนทานหน้าบูธตลอดวัน
7. ให้หัวหน้าตัดสินใจว่าจะเลือก Load Cell หรือ Active หลังมีข้อมูลข้างต้น ไม่เปลี่ยนขอบเขตหรือแก้ Excel โครงสร้างโดยอัตโนมัติ
