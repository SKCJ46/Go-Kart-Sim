# แนวทางผลิตเครื่องแรก — ตั้งแต่ออกแบบจนสั่งทำ

รวบรวมคำแนะนำในบทสนทนาเข้าโปรเจกต์ 24 ตุลาคม 2026 (Asia/Bangkok) เป็นข้อเสนอวิธีทำงาน ยังไม่ใช่การเลือกโรงงาน อนุมัติแบบ หรือสั่งซื้อ/ผลิต

แนวทางเสนอ: ทีมออกแบบใน Fusion 360 จ้างผลิตโครงเหล็กตามแบบ โครงหลักเชื่อมบนจิ๊ก โมดูลถอดด้วยน็อต ลองประกอบก่อนทำสี แล้วทีมกลับมารวมระบบและทดสอบ อ่านร่วมกับ [Context](../Gokart_IDEA/PROJECT_CONTEXT.md), [ผลศึกษาท่านั่ง/วัสดุ](seating-materials-assembly-th.md) และ [แผนเวลา](development-plan-th.md)

## ขั้นตอนและผลลัพธ์ก่อนผ่านไปงานถัดไป

| ขั้น | ทำอะไร | ผลลัพธ์ที่ต้องได้ |
|---|---|---|
| 1. เก็บมิติจริง | วัดเบาะ/ราง/ล้อ/ดุม GM5 และใช้แบบติดตั้งอุปกรณ์/จอจากรุ่นจริง | ตารางมิติ รูยึด ข้อจำกัด ระยะเคลื่อน และรายการที่ยังไม่รู้; อุปกรณ์ไม่เลือกรุ่นให้เผื่อพื้นที่แต่ยังไม่ปล่อยผลิตขายึดเฉพาะรุ่น |
| 2. ลองท่านั่ง | ทำ mock-up ปรับได้ด้วยไม้/เหล็กฉาก/โครงชั่วคราว ลองเอื้อม หมุนวง เหยียบสุด ขึ้นลงและมองจอ | ระยะที่ลองแล้ว ช่วงปรับ และปัญหาของแต่ละสรีระ ไม่อ้างมิติจากภาพ AI |
| 3. ทำ CAD และตรวจ | Mark ทำโครง/จุดยึด/โมดูล Chin ใส่ตำแหน่งไฟ/สายร่วมกัน ตรวจโหลด มวลเคลื่อน CG ระยะกวาดและการเข้าถึงน็อต | โมเดลเดียวสำหรับแบบประกอบ/ภาพฉาย ตารางโหลดและจุดตรวจ; ขนาดท่อ/เพลตตั้งต้นต้องตรวจตามแบบจริง |
| 4. เตรียมชุดขอราคา | แบบประกอบ/ชิ้นส่วน รายการวัสดุ ไฟล์ที่โรงงานใช้ได้ ข้อกำหนดเชื่อม งานผิว และจุดตรวจ | ชุดเอกสาร Revision เดียว ระบุผู้รับผิดชอบแบบคลี่ รัศมีดัด/แม่พิมพ์ และค่าคลาดเคลื่อนตามหน้าที่ |
| 5. ตรวจวิธีผลิตและราคา | โรงงานตรวจว่าดัด/เชื่อม/ประกอบได้ คุยการแก้แบบ แล้วแยกราคากับคิว | ใบเสนอราคาและขอบเขตชัดเจน การแก้แบบกลับให้ Mark ตรวจ/ออก Revision; ผู้มีอำนาจอนุมัติก่อนสั่ง |
| 6. ผลิตและลองประกอบ | ตัด/ดัด → จิ๊ก → แต้มเชื่อม → ตรวจมิติ → เชื่อมเต็ม → ตรวจซ้ำ → ลองประกอบ → แก้ | โครงตรง จุดต่อเข้ากันได้ ตรวจเบาะ ล้อ ขาจอและอุปกรณ์จริงก่อนทำสี |
| 7. ทำสีและประกอบจริง | หลังลองประกอบผ่าน จึงเก็บผิว ปิดจุดที่ห้ามสี ทำสี และประกอบโมดูล | ชุดกลไกเรียบร้อย น้ำหนักจริง/รายการรับงาน; ยังไม่เท่ากับผ่านโหลดหรือพร้อมโชว์ |
| 8. รวมระบบและส่งมอบ | ติดอุปกรณ์/ไฟ ตรวจโหลดจำลอง ระบบหยุด ระยะเคลื่อนก่อนให้คนขึ้น ทดสอบตามแผนแล้วเก็บแบบ as-built | ผลทดสอบ คู่มือ และแบบตรงของจริงสำหรับซ่อม/ผลิตซ้ำ; หากมีปัญหาสำคัญให้แก้ก่อนปล่อยโชว์ |

## วิธีผลิตแต่ละส่วนที่เสนอ

| ส่วน | วิธีเริ่มต้นที่เหมาะกับต้นแบบ |
|---|---|
| โครงท่อหลัก | ดัดท่อ เข้าปากท่อ เชื่อมบนจิ๊ก; จุดรับ Motion ผูกกับโครงรับแรง ไม่ยึดกับตัวถังตกแต่ง |
| คาน/จุดเสริม | ตัดท่อกล่องและเพลต ประกอบตามโหลดและจุดยึดที่ตรวจแล้ว |
| แท่นวง/แป้น/ขารองเบาะ | ตัดเลเซอร์ พับ/ขึ้นรูป เพิ่มค้ำตามแบบ ทำรอยต่อปรับและล็อกได้; เบาะต้องมี support ตามรูปทรง shell |
| ขาจอ | โครงมีค้ำ ถอดโมดูลได้ ตรวจแขนยื่น น้ำหนักจริงและแรงจาก Motion |
| พื้น | ตัด/พับอะลูมิเนียม ยึดกับคานรองด้วยน็อต |
| ตัวถัง/ฝาครอบ | เปรียบเทียบชิ้นสำเร็จรูปที่เหมาะสม แผ่นตัด/พับ หรือไฟเบอร์กลาสหากต้องการผิวโค้งเฉพาะ ยังไม่ลงทุนแม่พิมพ์จำนวนมากก่อนรูปทรงนิ่ง |
| ชิ้นตกแต่ง/ไกด์สาย | ใช้ H2C ทำต้นแบบและชิ้นที่เหมาะกับวัสดุ ไม่ใช้แทนจุดรับคน/Motion/จอ/FFB โดยไม่มีการออกแบบและตรวจ |

เสนอให้โรงงานหนึ่งแห่งรับผิดชอบความตรงของโครงเชื่อมหลัก จะรับช่วงงานตัด/พับ/สีได้เมื่อระบุผู้ตรวจรับแต่ละงาน ยังไม่มีการเลือกหรือรับรองผู้ผลิต

## ชุดเอกสารสำหรับขอราคา/สั่งทำ

- PDF แบบประกอบและแบบชิ้นส่วน: ขนาด จุดอ้างอิง หมายเลข วัสดุ ความหนา รู จุดพับ และเกณฑ์ตรวจ
- STEP โมเดลสามมิติ และ DXF งานแผ่น โดยตกลงว่าใครทำ/ตรวจแบบคลี่ก่อนตัด
- BOM จำนวน เกรด/มาตรฐานวัสดุ ขนาดท่อจริง และของที่ทีมส่งให้โรงงาน
- รายละเอียดท่อ: รูปทรง ความยาว มุม/รัศมีดัด การเข้าปากท่อ และแม่พิมพ์ที่ใช้
- ข้อกำหนดงานเชื่อม งานผิว จุดปิดก่อนสี เกลียว/ผิวประกบ และค่าคลาดเคลื่อนที่ตกลงตามหน้าที่
- Revision/วันที่ตรงกันทุกไฟล์ พร้อมขั้นตอนอนุมัติการเปลี่ยนแบบ ห้ามผลิตจากภาพแนวคิด
- ใบเสนอราคาแยกวัสดุ แรงงาน สี จิ๊ก ลองประกอบ VAT ขนส่ง คิวผลิต และเงื่อนไขแก้แบบ

[งบโครงสร้าง 80,000–130,000 บาท](structure-budget-th.md) ยังเป็นช่วงประมาณการรวมเผื่อ ไม่รวมออกแบบ/จิ๊ก/ทดสอบ/รวมระบบขั้นสุดท้าย ต้องแยกงานเหล่านี้ในราคาเพื่อไม่คิดซ้ำ คำแนะนำในเอกสารนี้ไม่ได้ยืนยันว่าผลิตได้ตามงบหรือเวลาโดยยังไม่มีแบบและใบเสนอราคา
