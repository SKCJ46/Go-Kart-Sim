## วิธีอ่าน

กำหนด S ที่จุดผิวเบาะรองก้นชิดพนักบนแนวกึ่งกลางเมื่อรางอยู่ตำแหน่งกลาง กำหนด X=0 ณ ตำแหน่ง S นี้และ X เพิ่มไปทางแป้น Z=0 คือพื้นบน cockpit; S มี Z=120 มม. ไม่ใช่ anatomical H-point หรือความสูงจากพื้นห้อง W คือศูนย์กลางวง B/T คือจุดสัมผัสเท้า

ระยะ S–W =400, S–แป้น=900 และ W–แป้น=500 มม. เป็นระยะฉายในแนวนอน ค่า 400/900 ใช้ S เดียวกัน ไม่มีการต่อ 400+900 เป็นระยะเบาะ–แป้น เมื่อเลื่อนเบาะต้องวัดจาก S ที่เลื่อนจริงอีกครั้ง ไม่ถือว่าระยะสัมพัทธ์คงเดิม

มุมพนัก 60° วัดจากแนวนอนชี้ไปท้ายรถถึงแนวพนัก ไม่ใช่มุมระหว่างก้นกับพนัก ตัวอย่างความสูง W=420 มม. จากพื้น cockpit คำนวณจาก S=120 บวกส่วนต่าง 300 มม.

ความยาวตัวรถ 1,800 และความกว้าง 1,300 มม. รวมล้อ/กันชน ไม่รวมจอ ขาจอส่วนยื่น ระยะกวาดของ Motion หรือทางเดิน ฐานล้ออ้างอิง 1,045 มม. ตำแหน่งแนวล้อที่ใช้วาดเป็นเพียงการจัด layout ภายในกรอบ ไม่ได้วัดจากรถจริง

## สิ่งที่ต้องวัดก่อนตัดท่อหรือเจาะรู

| ส่วน | ต้องได้ข้อมูล |
|---|---|
| GM5 | interface XYZ, รู/เกลียว, พิกัด/แนวแรง, ช่วงสูงต่ำและกวาดจริง, ข้อกำหนดการยึด/หยุด |
| เบาะ/cradle/slider | ผิวและรู shell, plate/spacer, ความสูงชุดประกอบ, รูรางและช่วงล็อกจริง |
| ฐานพวงมาลัย/แป้น | รุ่นจริง รูยึด envelope แรงสูงสุดที่อนุญาต สายและพื้นที่เครื่องมือ |
| จอ/ขาจอ | housing/VESA/depth/น้ำหนักจริง ระยะตา/FOV แขนยื่นและระยะชน |
| โครง | bend/cut list รัศมีดัด มุม/ระยะเข้าปากท่อ weld map/tolerance และจุดอ้างอิงจิ๊กที่ตรวจแล้ว |
| การใช้งาน | ผลลองหลายสรีระ จุดเข้าออก ความสูงจากพื้นห้อง ระยะกั้นผู้ชมและการขนย้าย |

## สร้างภาพซ้ำ

รันจาก root repository โดยมี Python, matplotlib และฟอนต์ Noto Sans Thai:

```bash
MPLCONFIGDIR=/tmp/mpl-dimension XDG_CACHE_HOME=/tmp/mpl-cache python docs/dimension-study/render-layout.py
```

Renderer ใช้พิกัดมิลลิเมตรและ equal aspect ในแต่ละมุม PNG/PDF/SVG เป็น output จากค่าชุดเดียว ไม่ควรวัดจากขนาดพิมพ์หรือภาพย่อ วัสดุ/ส่วนประกอบในแผนภาพเป็นสัญลักษณ์ ไม่ใช่ solid CAD, แบบท่อดัด หรือรูปทรงที่ผ่านการตรวจวิศวกรรม
