# แผนเครื่องพร้อมโชว์: งบและเกณฑ์ตรวจรับ

วันที่ 21 ตุลาคม 2026 (Asia/Bangkok) — อ่านร่วมกับ [Context หลัก](../Gokart_IDEA/PROJECT_CONTEXT.md) ซึ่งเป็นฐานข้อกำหนดเดียวของโครงการ

## 1. ข้อสรุปจากผู้ใช้และสมมติฐาน

**ยืนยันในแชท 21 ต.ค. 2026:** เครื่องแรกต้องพร้อมนำไปโชว์; ให้ประเมินงบ; ยังไม่เลือกรุ่น/แบรนด์อุปกรณ์ ต้องตกลงกับหัวหน้า; Mark ออกแบบโครงสร้าง/Hardware; Chin ออกแบบวงจรไฟฟ้าและอุปกรณ์ต่าง ๆ; ให้เสนอเกณฑ์ตรวจรับครบด้าน; หาก Motion/เกมไม่ตอบโจทย์ให้ศึกษาเพิ่มก่อน

**ฐานเสนอเพื่อประเมิน:** เครื่องหนึ่งชุดสำหรับสาธิตและให้ผู้ชมทดลองโดยมีเจ้าหน้าที่ประจำ สามจอ 27 นิ้ว PC ภายนอก และ GM5 ที่ต้องตรวจความพร้อม ใช้งานในอาคารตามข้อกำหนดอุปกรณ์ ไม่ใช่เครื่องเล่นแบบไร้ผู้ดูแล ยังไม่ยืนยันจำนวนผู้ทดลองต่อวัน สถานที่ วันโชว์ หรือชั่วโมงทีม วันที่ 29 ต.ค. เป็นเป้าหมายเสนอข้อมูล ไม่ใช่วันส่งเครื่องโชว์

เป้าหมายพร้อมโชว์หมายถึงงานประกอบ/ตกแต่งเรียบร้อย เล่นได้อย่างเสถียรในโปรไฟล์ที่ผ่านทดสอบ มีวิธีควบคุมผู้ทดลอง ขนย้ายและตั้งเครื่องคืนได้ พร้อมเอกสารและเจ้าหน้าที่ ส่วนการพร้อมขายและการรับรองผลิตภัณฑ์ต้องประเมินเพิ่ม

การมอบหมายซอฟต์แวร์/telemetry และผู้ตรวจรับยังต้องระบุ ชื่อผู้ทำแบบไม่ได้เท่ากับผู้อนุมัติรับรองงาน การขอประเมินงบและเกณฑ์ไม่ใช่การอนุมัติซื้อ ผลิต หรือติดต่อผู้ขาย

### รายการต้องเติมก่อนสรุปยอด

- **M_new:** เงินซื้อ/ซ่อม/เติมอุปกรณ์ Motion ที่ยังไม่รวมในตาราง เมื่อ GM5 เดิมพร้อมใช้และได้รับจัดสรรจึงใส่เฉพาะค่าเพิ่มจริงเป็นศูนย์ได้ ไม่ถือว่ายืนยันแล้ว
- **M_replace:** ราคาทดแทน GM5 ครบชุดสำหรับต้นทุนผลิตขาย ต้องแสดงแม้เครื่องโชว์ใช้ของเดิม ยังไม่มีราคาไทยยืนยัน
- **L:** เกม สิทธิ์ใช้งานโชว์/เชิงพาณิชย์ และซอฟต์แวร์ควบคุม แยกครั้งเดียว/รายปี/ต่อเครื่อง ตรวจของที่รวมในชุดก่อนนับ
- **T:** VAT/ภาษี/นำเข้า/ขนส่งที่ยังไม่อยู่ในแต่ละบรรทัด คิดเฉพาะส่วนเพิ่มจากฐานราคาที่บันทึก ห้ามบวก VAT ซ้ำกับราคาที่รวมแล้ว
- งบโชว์เฉพาะงาน เช่น เช่าบูธ เดินทาง เจ้าหน้าที่ อินเทอร์เน็ต และประกันตามเงื่อนไขผู้จัด แยกเป็นงบกิจกรรมเมื่อทราบสถานที่/จำนวนวัน ไม่อยู่ในต้นทุนเครื่อง

สูตรวางแผนเมื่อยังเผื่อความไม่แน่นอนเท่ากัน: **1.20 × (B + M_new + L + T)** ไม่บวกสำรอง 20% ซ้ำกับ B ที่รวมสำรองแล้ว หากรายการใดมีราคายืนยันและความเสี่ยงต่างกันให้กำหนดฐานสำรองใหม่พร้อมเหตุผล

งบเงินสดจริง = แยกรายการต้องจ่ายใหม่ออกจากแรงงานภายในและของเดิมที่ได้รับจัดสรร โดยยังเก็บต้นทุนทั้งหมดไว้ การหัก PC เดิมต้องยืนยันประสิทธิภาพ/สิทธิ์ใช้ก่อน ไม่ถือว่าอุปกรณ์มีอยู่แล้วโดยอัตโนมัติ งบพัฒนาข้างต้นไม่ควรหารเป็นต้นทุนต่อเครื่องที่ผลิตซ้ำโดยไม่มีจำนวนผลิตที่ตกลง

## 3. เกณฑ์ตรวจรับเครื่องพร้อมโชว์ — ร่างเสนอ v0.1

|---|---|---|

| A08 ภาพ/เสียง/การตอบสนอง | เกม/รถ/สนาม/จำนวนรถและ settings ตายตัว; ทดสอบฉากหนัก 30 นาที สามจอ เป้าหมายเฉลี่ย ≥60 fps และ 1% low ≥45 fps ไม่มีภาพดับหรือ USB หลุด; เริ่ม benchmark ที่รวม 5760×1080 เป็นฐานเสนอ ถ้าเปลี่ยนเป็น 7680×1440 ต้องประเมิน PC และทดสอบใหม่; เสียงไม่รบกวนคำสั่งเจ้าหน้าที่ | log frame time/settings และวิดีโอ — ผู้รับผิดชอบซอฟต์แวร์ที่ยังต้องระบุ ร่วม Chin |
| A09 Feeling | ผู้ขับโกคาร์ทจริงอย่างน้อย 3 คนเปรียบเทียบเปิด/ปิด Motion บนเงื่อนไขเดียวกัน; คะแนนเฉลี่ยเข้าโค้งและเบรก/เร่งแต่ละด้าน ≥3.5/5; ความสบายเฉลี่ย ≥4/5 โดย 5=สบายที่สุด; ผู้ทดสอบหยุดได้ทุกเวลา; บันทึกผู้หยุด/อาการเป็นข้อบกพร่องให้ทบทวน ไม่ตัดข้อมูลทิ้ง; เครื่องยนต์/ขอบสนาม/ท้ายปัดรายงานตาม telemetry จริง | แบบคะแนนแยกรายคน โปรไฟล์/ข้อจำกัด — ผู้รับผิดชอบซอฟต์แวร์ร่วมผู้ใช้ |
| A10 Active brake ถ้าเลือก | พิสูจน์แยกติดตั้งเบรกซ้าย–คันเร่งขวาได้ตามข้อกำหนด; calibration/แรงสูงสุด/ไฟดับ/การหยุดผ่านแผนผู้ผลิตและผู้ตรวจ; effect ที่นำไปสาธิตมีข้อมูลรองรับจริง ไม่อ้างครบทุกเกม | รุ่น/firmware ผังยึด ผลทดสอบ — Chin ร่วม Mark |
| A11 ความเสถียร | ผ่าน safety checks ก่อน endurance รวม ≥20 ชม. โดยมีโหลดและสลับผู้ขับตามแผน; ในนี้มีหนึ่งวันจำลองงานโชว์ 8 ชม. พักตามคู่มือ โดย GM5 ระบุโหลดรวม >200 กก. เล่นต่อเนื่องไม่เกิน 4 ชม. ต้องยืนยันช่วงพัก/duty cycle ก่อนทดสอบ 8 ชม.; และ ≥30 session × 5–10 นาที; ไม่มีระบบหลุด/ค้าง/ความร้อนเกิน/น็อตคลายที่ยังไม่แก้; log เวลาทำงานจริงและพักแยกกัน | log session อุณหภูมิ fault และผลตรวจจุดยึด — Mark/Chin; หากคู่มือห้าม duty นี้ให้ศึกษาใหม่ก่อนอนุมัติโชว์ |
| A12 งานผิวและความเรียบร้อย | ไม่มีคม เสี้ยน สายเปลือย/ปลั๊กห้อยในทางเดิน มี strain relief/ฉลาก; ป้ายแสดงรุ่นทดลอง ข้อจำกัดผู้ใช้ และขั้นตอนหยุด; ตรวจมองรอบเครื่องจาก 1 ม. ภายใต้ไฟสถานที่และถ่ายภาพก่อนแพ็ก | checklist/ภาพรอบเครื่อง — Mark/Chin |
| A13 ขนย้ายและตั้งคืน | ถอด–แพ็ก–ย้าย–ตั้งคืนครบ 2 รอบด้วยรถเข็น/อุปกรณ์ยกที่เหมาะกับน้ำหนักจริง; เจ้าหน้าที่สองคนจัดการได้โดยไม่บังคับยกทั้งเครื่อง; เป้าหมายตั้งเครื่องและตรวจพร้อมใช้ ≤60 นาที/รอบ ไม่เสียหายและสอบเทียบกลับได้ | น้ำหนักชิ้นยก เวลา แพ็กกิ้งและ checklist ตั้งคืน — Mark ร่วม Chin |
| A14 ปฏิบัติการหน้าบูธ | เจ้าหน้าที่อย่างน้อย 2 คนเรียนขั้นตอนและสาธิตเปิด–ปิด/ปรับคน/หยุด/ช่วยลง/กู้คืนได้คนละ 1 รอบ; cold start ถึงพร้อมสาธิต ≤10 นาที และเปลี่ยนผู้เล่น ≤3 นาทีเมื่อปรับในช่วงที่ทดสอบแล้ว; มีผู้ดูแลทุก session | คู่มือสั้น แบบบันทึกฝึก และเวลา — ผู้ใช้กำหนดเจ้าหน้าที่; Mark/Chin เตรียมวิธี |
| A15 สถานที่และสิทธิ์ | ก่อนออกงานต้องมีขนาด/พื้นรับโหลด ทางเข้าขนย้าย แหล่งจ่ายไฟ/ข้อกำหนดผู้จัด และสิทธิ์เกม/ซอฟต์แวร์ครอบคลุมการสาธิตจริง; ทดลองเปิดเล่นโดยไม่พึ่งอินเทอร์เน็ตหากงานต้อง offline หรือยืนยันเครือข่ายสำรอง | site checklist และหลักฐานสิทธิ์ — เจ้าของโครงการร่วม Chin |
| A16 เอกสาร/ปล่อยเครื่อง | มี as-built, BOM, serial/firmware, ผังไฟ/จุดตัดไฟ, โปรไฟล์สำรองและวิธีกู้, checklist ก่อนใช้/บำรุง/ขนย้าย, risk register และผล A01–A15; ไม่มีปัญหาความปลอดภัยหรือความเสถียรค้าง ผู้ตรวจแต่ละด้านและผู้อนุมัติปล่อยเครื่องที่ต้องแต่งตั้งลงชื่อ | แฟ้มตรวจรับพร้อมวันที่และข้อจำกัด — Mark/Chin จัดทำ ผู้อนุมัติยังไม่ระบุ |

**จุดที่ต้องปิดก่อนให้คนขึ้น/ก่อนออกโชว์:** ระบุตัวเลขโหลด/การเสียรูป แรงขัน ระยะปลอดภัย เวลา/ระยะหยุด ค่าตรวจไฟ และอุณหภูมิจากอุปกรณ์จริงให้ครบใน test sheet ผู้ตรวจไม่อาจยกเว้นอันตรายเพื่อให้ทันงาน หากรายการสำคัญยังไม่ผ่านให้คงสถานะไม่พร้อมโชว์และศึกษา/แก้ไขก่อน

**การจำแนกปัญหา:** S1 เสี่ยงอันตราย → หยุดและกั้นเครื่อง; S2 ฟังก์ชันโชว์หลัก/ความเสถียรไม่ผ่าน → ยังไม่ปล่อยโชว์; S3 งานผิวเล็กน้อย → อาจรับแบบมีรายการแก้ไขได้เมื่อผู้อนุมัติที่ระบุลงชื่อ โดยไม่ลดความปลอดภัย/ความสามารถหลัก หลังแก้ปัญหาต้องทดสอบซ้ำเฉพาะรายการที่ได้รับผลกระทบและบันทึก revision

ข้อมูลที่บันทึกทุก test: รหัส วันที่ ผู้ทำ/ผู้ตรวจ รุ่น/serial/firmware เกม/รถ/สนาม/settings โปรไฟล์ โหลด/CG เครื่องมือ/วิธีวัด ผลจริงเทียบเกณฑ์ ผ่าน/ไม่ผ่าน/ยังไม่ทดสอบ ภาพ/log และลิงก์ปัญหา การทดสอบเหล่านี้เป็นเกณฑ์ต้นแบบ ไม่ใช่ผลทดสอบอายุใช้งานหรือการรับรองมาตรฐานจำหน่าย

### หลักฐานเครื่องกลเพิ่มเติม 21 ต.ค.

[ผลศึกษาท่านั่ง/วัสดุ/ประกอบ](seating-materials-assembly-th.md) มีการอ่านภาพคู่มือ GM5 ครบแล้ว (PDF หน้า 2 / เลขพิมพ์ 1) พบเงื่อนไขโหลดรวมเกิน 200 กก. จำกัดการเล่นต่อเนื่องไม่เกิน 4 ชม. ไม่ได้ระบุช่วงพัก จึงยังวางแผนโชว์ 8 ชม. ต่อเนื่องไม่ได้ หาก cockpit เคลื่อน 85–135 กก. รวมผู้ขับ 120 กก. จะเป็น 205–255 กก. ก่อนแจกแจงส่วนอื่น ต้องยืนยันน้ำหนักและเงื่อนไขพักให้ครบก่อนทดสอบ/ออกงาน ไม่ถือว่า payload 300 กก. รับรอง duty ทั้งวัน

## 4. แบ่งงานและจุดตัดสินใจ

| งาน | เจ้าของตามคำสั่ง/ข้อเสนอ | ผลส่งมอบก่อนอนุมัติผลิต |
|---|---|---|
| ท่านั่ง layout โครงและจุดยึด Motion ขาจอ น้ำหนัก/CG และขนย้าย | **Mark — ยืนยัน** | CAD/แบบ ตารางโหลด BOM เครื่องกล และแผนตรวจโครง |
| วงจร ไฟฟ้า อุปกรณ์/การเชื่อมต่อ E-stop สายและตารางโหลด | **Chin — ยืนยัน** | ผังไฟ รายการอุปกรณ์/ตัวเลือก และแผนทดสอบ failure modes |
| เลือกเกม telemetry โปรไฟล์ benchmark และ backup | **ยังต้องระบุ**; เสนอให้ Chin ประสานโดยไม่ถือว่ามอบหมายแล้ว | ผลทดสอบเกม/GM5 และรายการ effect ที่ทำได้ |
| รวม BOM และงบ | Mark + Chin เตรียมตามหมวด; เจ้าของโครงการพิจารณา | ต้นทุนเครื่อง/พัฒนา/PC เงินสด/ของเดิม ภาษี/ส่ง lead time |
| แบรนด์/ระดับอุปกรณ์ เพดานงบ และอนุมัติปล่อยเครื่อง | หัวหน้า/ผู้มีอำนาจที่ยังต้องระบุ | บันทึกอนุมัติจากข้อมูลทดสอบและราคา |

ลำดับเสนอ: ตรวจ GM5 และ telemetry → mock-up/โหลด/จุดยึด → layout/ผังไฟ/ตัวเลือก/BOM → ให้หัวหน้าเลือกรุ่นและงบ → ตรวจแบบก่อนผลิต → ทดสอบด้วยโหลดจำลอง → ทดลองคน → endurance/ซ้อมโชว์/ตรวจสถานที่ → ลงชื่อปล่อยเครื่อง

หาก GM5 หรือเกมไม่ผ่าน ให้เก็บสาเหตุ/ข้อจำกัด ทดสอบซ้ำแบบควบคุมตัวแปร และเปรียบเทียบแนวทางพร้อมผลกระทบงบ/เวลา แล้วกลับมาขอข้อสรุป ไม่เปลี่ยน Motion เกม หรือขอบเขตด้วยตัวเอง งานเพิ่มนี้ยังไม่มีระยะเวลารับประกัน

เรื่องยังต้องตกลง: วัน/สถานที่โชว์และจำนวน session ต่อวัน ชั่วโมง Mark/Chin ผู้รับผิดชอบซอฟต์แวร์ ผู้ตรวจวิศวกรรม/ผู้ปล่อยเครื่อง ความพร้อม GM5 แบรนด์/ระดับอุปกรณ์ สถานะ Active brake งบจริง และจำนวนเครื่องที่จะอนุมัติทำ
