# Drawing สามมุม — Rev A

สร้าง 21 ตุลาคม 2026; เก็บเข้าโปรเจกต์ 23 ตุลาคม 2026 (Asia/Bangkok)

- ที่มา: ภาพ Dimension Study v04 ที่ผู้ใช้แนบ แล้วขอ “Drawing … Thrit view” ผู้ช่วยตีความเป็นสามมุมจัดแบบ Third-angle: มุมบนอยู่เหนือมุมหน้า และมุมขวาอยู่ขวามือ
- [PNG](kart-three-view-rev-a.png) คือภาพฉบับแก้ล่าสุดที่สร้างด้วย image_gen จากรอบเดิม; ไม่ได้สร้างหรือแก้ภาพใหม่ในรอบอัปเดต Context
- [PDF A3 แนวนอน](kart-three-view-rev-a.pdf) ฝังภาพ raster เดียวกัน ไม่ใช่ CAD/vector และสเกลระบุ NTS
- ตัวเลขเสนอ: ตัวรถ 1,800 × 1,300 มม., ฐานล้อ 1,045, S–W 400, S–แป้น 900, W–แป้น 500, W สูงกว่า S 300, S สูงจากพื้น cockpit 120 มม. ใช้ค่าระยะจาก [แผ่นพิกัด v04.1](../../../docs/dimension-study/kart-dimension-study-v04.pdf) ประกอบ ไม่วัดจากภาพ
- จุด S เป็น datum ผิวเบาะที่ตำแหน่งรางกลาง ไม่ใช่ anatomical H-point ความสูงจากพื้น cockpit ไม่ใช่ความสูงจากพื้นห้อง
- ยังไม่ตรวจความตรงกันของภาพฉาย สเกล รูปทรง ตำแหน่งหัวลูกศรและจุดอ้างอิง มิติรู จุดยึด GM5 โหลด และความสูงติดตั้งต้องวัด/ตรวจใน CAD
- ห้ามใช้เป็นแบบผลิตหรือเป็นหลักฐานอนุมัติวัสดุ/โหลด เครื่องหมายและรายละเอียดกลไกในภาพสร้างอาจไม่ตรงอุปกรณ์จริง
